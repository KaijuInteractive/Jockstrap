# 🩲 Jockstrap

**A programming language with support where it counts.**

Jockstrap is an experimental programming language and interpreter built from scratch in C++ by Kaiju Interactive.

The project explores the fundamentals of language design, including lexical analysis, parsing, variables, control flow, and execution — wrapped in a completely unnecessary underwear-themed syntax.

## 🧠 Current Features

- Custom lexer
- Custom parser
- String variables
- Numeric variables
- Console output
- Conditional statements
- Custom `.jock` source files
- Underwear-based language keywords

## 🩲 The Language

| Jockstrap | Meaning |
|---|---|
| `BRIEFS` | Declare a variable |
| `EXPOSE` | Print/output |
| `TIGHT` | Conditional (`if`) |
| `STRAP` | Loop (`while`) |

## 💻 Example

```jockstrap
BRIEFS message = "Hello from Jockstrap";

EXPOSE message;
